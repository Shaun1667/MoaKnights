## 다른 PC 준비 (처음 한 번)
1. Git으로 받기: `git clone` 뒤 `main`. 아트 원본(`ArtSource/`)과 FBX도 저장소에 들어 있다 (LFS 안 씀, `.git` 약 600MB).
2. Unity Hub에서 **6000.3.25f1** 설치 (버전 변경 금지). `MoaKnights/` 폴더를 프로젝트로 연다. 첫 불러오기는 모델이 많아 오래 걸린다 (이 PC에서 7분쯤 멈춘 적 있음).
3. 메뉴 `MoaKnights/Setup/Run All` 한 번 → `Scenes/Battle.unity` 플레이. 씬 · 데이터가 커밋본과 같아야 한다 (`git status` 깨끗).
4. 테스트: Window > General > Test Runner > EditMode 전체 → 199개 통과.
5. Claude Code 도구 (필요할 때만):
   - Unity 연결: 프로젝트에 `com.unity.ai.assistant` 패키지가 있다. 에디터 창이 뒤에 있으면 명령이 멈출 수 있음 → Unity 창을 앞으로.
   - 난이도 측정 `Tools/BalanceSim/run.sh`: Git Bash + Python 3 + Unity에 들어 있는 Mono. Unity 설치 경로가 다르면 `MONO` 환경 변수로 `.../Editor/Data/MonoBleedingEdge`를 준다.
   - 모델 만들기 `Tools/Blender/build_models.sh`: Blender 위치가 `D:/blender.exe`가 아니면 `BLENDER` 환경 변수로 준다.
   - Varco 3D(새 모델 만들 때만): 그 PC의 Claude에 Varco 연결을 다시 로그인. 포인트를 쓰기 전에는 항상 사용자에게 묻는다.
6. 저장 파일: `Application.persistentDataPath/profile.json` (PC마다 따로, 저장소에 없음). 처음 상태는 디버그 창 "프로필 초기화".
